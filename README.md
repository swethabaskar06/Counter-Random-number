# React Counter & Random Number Generator

A simple React.js project created to practice **state management, event handling, and conditional rendering** using React Hooks.

## 📌 Project Description

This project contains two small interactive applications:

### 🔢 Counter

* Displays the current counter value.
* **Increment** button increases the value.
* **Decrement** button decreases the value.
* **Reset** button sets the counter back to zero.
* Uses React's `useState` hook to manage the counter state.

### 🎲 Random Number Generator

* Generates a random number when the user clicks the button.
* Demonstrates how React state can be updated dynamically.
* Uses JavaScript's `Math.random()` method.

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in the terminal.
3. Install dependencies:

```bash
npm install
```

4. Start the React application:

```bash
npm run dev
```

5. Open the local URL shown in the terminal in your browser.
